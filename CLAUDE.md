# Titian — rules for agents

Indonesian SD learning map: micro-topics + prerequisite graph built from the official
Capaian Pembelajaran (Keputusan Kepala BSKAP 046/H/KR/2025). Solo project, public repo.

## Hard rules
- **Clean-room.** Never open, copy, quote or feed Marble's os-taxonomy data (ODbL + CC BY-SA)
  into any step. Its idea and its general shape are fine. Its content is not.
- Content is Indonesian, keys are English. Parent prompts use `{{nama}}`, spoken register.
- `data/` is generated by `node scripts/build.mjs` from `authoring/` + `data/standards.json`.
  Edit `authoring/`, never `data/topics.json` by hand.
- `node scripts/validate.mjs` must pass before every commit.
- No Agama, no SMP/SMA in v1. No analytics, no contact channel on the site.
